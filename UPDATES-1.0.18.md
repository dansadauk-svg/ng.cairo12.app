Cairo12 1.0.18 — shipping-inclusive shopping

Install Cairo12 Core 0.8.0 before using this app version.

Admin dashboard → Settings:
• Set Standard shipping to Kano and the full Fast Track shipping rate in Naira/kg.
• Prices include configured Standard shipping per piece. Regular/Heavy configured weights still apply.
• Fast Track replaces Standard at checkout. Only the difference increases the displayed total.
• Markup applies to the abaya cost before shipping. Existing orders retain recorded totals.
• Add a https://whatsapp.com/channel/… URL to enable the channel button; leave blank to hide.

Notifications & ads:
• Create full-screen promotional campaigns using a portrait image URL or the selected product thumbnail.
• Set title, message, button text, audience platform, dates and once/daily frequency.
• Android newcomers receive a one-time notification invitation with Enable and Maybe later. Android 13+ then asks permission. Sign-in remains required for device registration and order alerts.
• Firebase project and existing GitHub signing secrets are unchanged.

Shopping:
• Product picture/selected video thumbnail appears in options, with an enlarged preview.
• Size choices, quantity controls, a conditional Other colour field and a fixed Add to bag action.
• Back-to-top and WhatsApp channel controls in the discovery feed.
• New orders collect abayas and selected shipping together; cargo must not be charged again.

Build:
• Version code 19; version name 1.0.18; target and compile SDK 36.
• Use the existing GitHub Actions workflow and existing signing secrets for release APK/AAB.
• Do not replace the production keystore.
